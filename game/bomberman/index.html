Kontrol Permainan

Pemain 1 (Utama)

  • ←↑↓→ Jalan
  • SpasiAlt Pasang Bom
  • EBX Ledakkan Remote Bom
  • FC Lempar Bom (3 petak)

Pemain 2 (Lokal)

  • WASD Jalan
  • Shift Pasang Bom
  • Q Ledakkan Remote Bom
  • R Lempar Bom
  • M Mute / Unmute Suara
  • Enter Mulai Ulang (Restart)
  • Esc Menu Utama

Variasi Power-Up & Bonus

1. Serangan (Offensive)

  • Bomb Up Menambah kuota bom aktif sekaligus (+1).
  • Bom Tembus (Spike Bomb) Api ledakan menembus beberapa balok rapuh sekaligus dalam satu garis.
  • Remote Bom (Detonator) Bom tidak meledak dengan timer, melainkan via tombol pemicu (E/B).

2. Interaksi Bom (Utility)

  • Tendang Bom (Bomb Kick) Tabrak bom untuk meluncurkannya menjauh hingga menabrak dinding/musuh.
  • Lempar Bom (Bomb Throw) Ambil dan lemparkan bom 3 petak melewati dinding/balok kayu (F/C).
  • Tembus Bom (Bomb Pass) Bebas berjalan melewati bom tanpa terhalang sudut buntu.

3. Pertahanan & Mobilitas

  • Perisai (Shield / Heart) Melindungi pemain dari 1x serangan musuh atau ledakan fatal.
  • Tembus Tembok (Wall Pass) Menembus balok kayu rapuh seolah menjadi hantu transparan.
  • Speed Up Menambah kelincahan kecepatan jalan pemain.

4. Kutukan Tengkorak (Item Negatif)

  • Diare Bom Otomatis menjatuhkan bom di setiap langkah tanpa bisa dicegah!
  • Siput (Slow) Kecepatan lari menjadi sangat lambat selama 12 detik.
  • Kontrol Terbalik Arah kemudi terbalik: atas jadi bawah, kiri jadi kanan!
  • Amnesia Lupa cara menaruh bom sama sekali selama kutukan aktif.
