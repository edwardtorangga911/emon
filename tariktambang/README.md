# Tarik Tambang Matematika 🪢🏆

Game edukasi interaktif **Tarik Tambang Matematika (Edisi Arena Juara)** dengan grafis aksi modern, sistem **combo streak**, **pengatur waktu per soal**, **kustomisasi nama pemain**, dan **34 mode pembelajaran matematika bilangan bulat**. Dirancang khusus untuk **Interactive Flat Panel (IFP)**, Smart Board sekolah, smartphone/tablet (landscape), dan PC/Laptop.

---

## 🚀 Cara Menjalankan Game

1. Buka file [**`index.html`**](file:///C:/Users/Admin/Desktop/tarik%20tambang/index.html) menggunakan peramban web modern apa pun (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari, dll).
2. Game ini **100% offline**, mandiri (*standalone*), tanpa instalasi tambahan dan tanpa ketergantungan internet.

## ✨ Fitur-Fitur Unggulan

1. **🏷️ Kustomisasi Nama Pemain / Tim**:
   - Guru atau murid dapat memasukkan nama pemain/tim sebelum mulai (misal: "Tim Garuda" vs "Tim Rajawali", atau nama murid langsung).
   - Nama otomatis muncul di papan skor, panel permainan, pengukur tegangan, dan panggung kemenangan.

2. **⏱️ Pengatur Batas Waktu Soal (Timer)**:
   - Pilihan: **Santai (Tanpa Batas)**, **20 Detik**, atau **12 Detik (Tantangan Cepat)**.
   - Bilah animasi waktu bergerak menyusut secara real-time di bawah soal. Jika waktu habis, soal berganti otomatis dengan nada penanda waktu.

3. **🔥 Sistem Combo Streak (Tarikan Ekstra)**:
   - Menjawab berturut-turut tanpa salah memicu lencana `🔥 2x`, `🔥 3x`, hingga `⚡ 5x COMBO!`.
   - Pada streak 3x atau lebih, tarikan tali mendapatkan daya dorong ekstra (+30% kekuatan tarik) dan efek suara kemenangan kombo!

4. **⚠️ Deteksi Ketegangan Kritis Tali (Match Point)**:
   - Ketika skor pemain terpaut 1 poin dari target kemenangan, spanduk bahaya merah berdenyut menyala: *“MATCH POINT! KEMENANGAN SUDAH DEKAT!”*.
   - Tali tambang dan arena bergetar secara dinamis menandakan ketegangan maksimal pertandingan.

5. **⌨️ Keypad Layar Sentuh Lengkap (Dengan Koma `,` & Minus `±`)**:
   - Susunan keypad 3×5 IFP & Layar Sentuh:
     ```
     [ 1 ] [ 2 ] [ 3 ]
     [ 4 ] [ 5 ] [ 6 ]
     [ 7 ] [ 8 ] [ 9 ]
     [ ± ] [ 0 ] [ , ]
     [ C ] [ ⌫ ] [ KIRIM ↵ ]
     ```
   - **Tombol `±`**: Menambah/menghapus tanda minus `-` untuk mode bilangan bulat negatif.
   - **Tombol `,` (Koma)**: Memasukkan tanda desimal koma (misal: `34,5`, `0,25`). Otomatis mencegah koma ganda atau format tidak valid.
   - **Tombol `⌫` (Backspace)**: Menghapus 1 digit angka terakhir.
   - **Tombol `C` (Clear)**: Mengosongkan isian jawaban.
   - **Tombol `KIRIM ↵`**: Tombol aksi hijau tebal untuk mengirim jawaban.

6. **✨ Tombol Opsi Desimal Global (Diterapkan ke Semua Mode)**:
   - Terdapat tombol toggle cepat di **Bar Atas** (`🔢 Desimal: OFF` ↔ `✨ Desimal: ON (,)`) dan opsi di **Menu Utama**.
   - Ketika aktif, seluruh 34 mode matematika secara cerdas menghasilkan soal dengan nilai desimal berkoma (misal: perkalian desimal `1,5 × 20`, luas persegi sisi desimal `4,5`, persentase desimal, dsb).
   - Mode mandiri desimal yang terpisah di menu telah dihilangkan agar katalog mode rapi dan terorganisir, sementara kemampuan desimal tetap 100% tersedia dan dapat diterapkan ke mode apa pun secara fleksibel!

7. **💡 Sistem Petunjuk Otomatis (Hint)**:
   - Jika pemain salah menjawab 2 kali pada soal yang sama, petunjuk edukatif langsung muncul membantu memahami konsep.

8. **🎯 Riwayat 3 Jawaban Terakhir (Mini Dots)**:
   - Lampu indikator bulat mini (🟢 hijau untuk benar, 🔴 merah untuk salah) di bawah kotak jawaban memudahkan guru melihat konsistensi murid.

9. **📊 Statistik Pertandingan Lengkap & Tombol Tanding Ulang**:
   - Menampilkan: Durasi Waktu Bermain, Total Soal Terjawab, dan Rekor Combo Tertinggi.
   - Dilengkapi tombol **🔄 Tanding Ulang (Rematch)** untuk langsung memulai babak baru tanpa harus kembali ke menu.

## 🧮 Daftar 34 Mode Permainan Matematika (Bilangan Bulat)

### 🌱 Kategori Dasar (SD Kelas 1-2)
- **+ Tambah (1 Digit)**: Penjumlahan dasar 1 angka.
- **− Kurang (1 Digit)**: Pengurangan dasar 1 angka.
- **🍉 Hitung Buah (Visual)**: Berhitung visual jumlah buah.
- **+2 2 Digit Tambah**: Penjumlahan puluhan.
- **-2 -2 Digit Kurang**: Pengurangan puluhan.
- **🔢 Pola Angka**: Menemukan angka kelanjutan deret.
- **XVIII Angka Romawi**: Membaca angka romawi dasar.

### ⚡ Kategori Aritmatika (SD Kelas 3-4)
- **−/+ Bilangan Negatif**: Penjumlahan, pengurangan, perkalian, pembagian bilangan negatif (SD 6 / SMP).
- **× Kali Dasar**: Perkalian bilangan 1 digit.
- **÷ Bagi Dasar**: Pembagian bulat.
- **± Campuran (+−×÷)**: Operasi campuran bergantian.
- **+− Tambah Kurang (3 Angka)**: Operasi berantai 3 bilangan.
- **×÷ Kali Bagi (3 Angka)**: Perkalian dan pembagian berantai.
- **% Persentase**: Menghitung persen bulat.
- **➗ Sisa Bagi (Modulus)**: Sisa hasil pembagian bulat.
- **? Semua Mode Acak**: Mengacak seluruh jenis soal.

### 🚀 Kategori Lanjutan (SD Kelas 5-6)
- **x² Pangkat 2**: Kuadrat bilangan bulat.
- **x³ Pangkat 3**: Kubik bilangan bulat.
- **√ Akar Kuadrat**: Akar pangkat dua bilangan bulat.
- **∛ Akar Pangkat 3**: Akar pangkat tiga bilangan bulat.
- **FPB (Faktor Persekutuan Terbesar)**: Menghitung faktor terbesar.
- **KPK (Kelipatan Persekutuan Terkecil)**: Menghitung kelipatan terkecil.
- **🧩 Aljabar X**: Mencari nilai x pada persamaan linear sederhana.

### 📐 Kategori Satuan & Geometri
- **🔺 Segitiga**: Luas segitiga `(a × t) ÷ 2` dan keliling segitiga.
- **🚀 Kecepatan**: Rumus Jarak, Kecepatan, dan Waktu (`km/jam`).
- **🚰 Debit Air**: Rumus Debit, Volume, dan Waktu Aliran (`liter/detik`).
- **🕐 Waktu**: Konversi jam dan menit.
- **📏 Jarak**: Konversi kilometer, meter, centimeter, milimeter.
- **⚖️ Berat**: Konversi kilogram, gram, ton, ons.
- **🧪 Volume**: Konversi liter dan mililiter.
- **🟩 Luas**: Luas persegi dan persegi panjang.
- **🔲 Keliling**: Keliling bangun datar.
- **💵 Uang Belanja**: Menghitung kembalian uang belanja.
- **📐 Sudut**: Menghitung besar derajat sudut geometri.

## ⌨️ Kontrol Keyboard (Desktop / Laptop)

- **Player 1 (Kiri)**:
  - Angka: `0`–`9` (baris angka atas)
  - Minus / Negatif: `-` atau `_`
  - Koma Desimal: `,` (koma) atau `.` (titik)
  - Hapus 1 angka: `Backspace`
  - Hapus semua: `C`
  - Kirim Jawaban: `Enter`

- **Player 2 (Kanan - Numpad)**:
  - Angka: `0`–`9` (Numpad)
  - Minus / Negatif: `Numpad -` (NumpadSubtract)
  - Koma Desimal: `Numpad .` (NumpadDecimal), `,`, atau `.`
  - Hapus 1 angka: `Delete`
  - Kirim Jawaban: `Numpad Enter`
